This project is a Direct Messaging Chat application developed for ICS 32. 
The program allows users to send and receive direct messages through the DSP server using a custom messaging protocol. It includes a DirectMessenger module that handles communication with the server, including sending messages, retrieving new messages, and retrieving message history.

The application also features a graphical user interface (GUI) built with Tkinter. Users can add contacts, select recipients, view message history, and send new messages through an interactive interface. Messages and contacts are stored locally using a profile system, allowing data to persist between sessions without requiring a server connection. The GUI automatically retrieves new messages while running and clearly distinguishes between sent and received messages.
